

If you mean **moving the metadata/description and CSS out of `layout.tsx` into a separate `main-header.js` component**, the important distinction is:

- **Metadata should stay in `layout.tsx` or `page.tsx`** using Next.js Metadata API.
    
- **Header UI and its CSS can be moved into a reusable `MainHeader` component.**
    
- Don't move `<title>`/metadata into `MainHeader` just to separate it; metadata is handled by Next.js separately from UI.
    

Example structure:

```text
app/
├── layout.tsx
├── page.tsx
├── global.css
└── components/
    ├── main-header.js
    └── main-header.module.css
```

### `layout.tsx`

```tsx
import MainHeader from "./components/main-header";
import "./global.css";

export const metadata = {
  title: "Food App",
  description: "Discover and share delicious meals",
};

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        <MainHeader />
        {children}
      </body>
    </html>
  );
}
```

### `main-header.js`

```jsx
import classes from "./main-header.module.css";

export default function MainHeader() {
  return (
    <header className={classes.header}>
      <h1>Food App</h1>
    </header>
  );
}
```

### `main-header.module.css`

```css
.header {
  padding: 20px;
}
```

### The mental model

```text
layout.tsx
│
├── Metadata
│   ├── title
│   └── description
│
├── MainHeader
│   └── main-header.module.css
│
└── {children}
    ├── page.tsx
    ├── meals/page.tsx
    └── community/page.tsx
```

**Interview takeaway:**

> **Metadata belongs to Next.js's Metadata API; UI belongs in React components; component-specific styling can be separated into CSS Modules.**
